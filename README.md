# Quotes Scraper

Proyek web scraping pertamaku: ambil data quotes dari 3 halaman website, rapikan datanya, lalu bikin laporan Excel otomatis.

## Yang dikerjakan
- Ambil quote dan nama penulis dari 3 halaman
- Gabung jadi satu tabel (Python + Pandas)
- Cari penulis yang paling sering muncul
- Simpan hasil ke Excel: sheet "Data Lengkap" dan sheet "Ringkasan"

## Tools
Python, BeautifulSoup, Pandas, Google Colab

## Isi repository
- Notebook: kode lengkapnya
- laporan_quotes.xlsx: contoh hasil laporan

## Catatan
Dibuat sambil belajar scraping dari nol, termasuk beresin masalah encoding dan pagination.
